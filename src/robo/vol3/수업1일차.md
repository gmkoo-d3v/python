# 로봇기초 1일차 실습

교재 1~2장 중 핵심 실습을 진행합니다. Python 3.12와 uv가 필요합니다.
배포 ZIP을 풀어 생긴 `코드묶음` 폴더가 실습 작업 공간입니다. `vol3`는 그 안의 코드 묶음이고, 가상 환경은 `코드묶음`에 하나만 둡니다. 폴더 경로는 따옴표로 감싸세요.

## 수업 전 환경 준비

`코드묶음/pyproject.toml`에 첫날 네 패키지만 선언되어 있습니다. `코드묶음` 폴더에서 한 번만 동기화하면 `코드묶음/.venv`가 만들어지고, `vol3`를 포함한 하위 폴더가 같은 환경을 씁니다.

```sh
cd "코드묶음"
uv sync --python 3.12
```

이미 `.venv`가 있으면 `uv sync`가 같은 환경을 갱신합니다. 별도로 `uv venv`나 `uv pip install`을 실행할 필요가 없습니다.
패키지 설치에는 인터넷이 필요하며, 별도 데이터·모델 가중치는 받지 않습니다.
`uv run`은 상위 폴더의 `pyproject.toml`을 찾으므로 `vol3` 안에서 실행해도 같은 환경을 씁니다.

```sh
cd "코드묶음/vol3"
uv run python 01-what-is-a-robot/b15_env_check.py
```

버전 출력과 `렌더 시험 : (64, 64, 3)`을 확인합니다. 렌더 오류는 강사에게 공유하세요.
그래프의 한글이 깨지면 해당 예제의 AppleGothic을 설치된 한글 글꼴로 바꿉니다.

## 필수 실습 · 각 20분

명령의 시작 위치는 `코드묶음/vol3`입니다. 예측 3분, 실행·비교 10분, 기록·설명 7분으로 진행합니다.

| 차시 | 파일 | 비교할 옵션 | 기록할 것 |
|---|---|---|---|
| 1 | 01-what-is-a-robot/b04_slip_noise.py | 기본값 / --slip 0.4 | 열린·닫힌 고리 평균 오차와 이유 |
| 2 | 01-what-is-a-robot/b13_period.py | 기본값 / --gain 2 | 주기별 지나침, 이득×주기 |
| 3 | 01-what-is-a-robot/b23_three_tries.py | 기본값 / --obstacle-y 0.6 | 세 규칙의 충돌·도착 여부와 이유 |
| 4 | 02-frames-rotations/b08_order.py | 옵션 없음 | 회전 순서별 앞 방향 |
| 5 | 02-frames-rotations/b18_homogeneous.py | 기본값 / --yaw 180 | 로봇 좌표와 방 좌표 왕복 검산 |

```sh
uv run python 01-what-is-a-robot/b04_slip_noise.py
uv run python 01-what-is-a-robot/b04_slip_noise.py --slip 0.4
uv run python 01-what-is-a-robot/b13_period.py
uv run python 01-what-is-a-robot/b13_period.py --gain 2
uv run python 01-what-is-a-robot/b23_three_tries.py
uv run python 01-what-is-a-robot/b23_three_tries.py --obstacle-y 0.6
uv run python 02-frames-rotations/b08_order.py
uv run python 02-frames-rotations/b18_homogeneous.py
uv run python 02-frames-rotations/b18_homogeneous.py --yaw 180
```

그림은 실행한 현재 폴더에 저장됩니다. `control_period.png`는 마지막 실행 결과입니다.
슬라이드는 장 폴더에서 실행하는 짧은 명령을 사용합니다. 위 명령과 같은 파일입니다.
옵션은 한 번 실행할 때만 적용됩니다. 공용 모듈을 편집하거나 값을 되돌릴 필요가 없습니다.

## 선택 실습

1차시: b04에 `--noise 0.1` 추가. 2차시: b14_delay.py. 3차시: b25_avoid_noisy.py.
4차시: b06_deg_rad.py. 5차시: b19_chain.py와 b21_mujoco_check.py.
쿼터니언 합성·SLERP·자이로 적분은 덱 뒤쪽 선택 자료로 남깁니다.

## 교재와 배포 코드 이름 대응

| 교재·이전 슬라이드 | 실제 파일 |
|---|---|
| v3c01 | 01-what-is-a-robot |
| v3c02 | 02-frames-rotations |
| 점로봇.py | point_robot.py |
| 상자장면.py | box_scene.py |
| 피하기도구.py | avoidance_tools.py |
| 회전도구.py | rotation_tools.py |
| 쿼터니언도구.py | quaternion_tools.py |
| 자이로데이터.py | gyro_data.py |

교재 59쪽의 '하늘 보기(피치 +90도)'는 이 코드의 축 약속에서 '아래 보기'입니다.
+x 앞, +y 왼쪽, +z 위에서 `Ry(90) @ [1,0,0] = [0,0,-1]`입니다.
`이득×주기` 안정 조건은 지연·속도 제한 없는 1차원 모델에만 적용합니다.

한글 파일명의 유니코드 정규화 차이로 생기는 import 오류를 피하기 위해 공용 모듈 이름을 영문으로 통일했습니다. 변수와 함수의 한글 이름은 유지합니다.
