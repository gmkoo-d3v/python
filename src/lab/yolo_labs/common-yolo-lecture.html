03 · pick_device()

ultralytics는 CUDA를 “번호”로 받는다

PyTorch에서는 torch.device("cuda")였지만, ultralytics API는 device=0 같은 번호를 기대합니다.

common_yolo.py · 18–20행원문 그대로
def pick_device() -> int | str:
    """cuda는 번호로, 그 밖에는 이름으로 넘긴다(ultralytics 규칙)."""
    return 0 if torch.cuda.is_available() else "mps" if torch.backends.mps.is_available() else "cpu"
🔬 정확히는

반환형이 int | str입니다. CUDA가 있으면 정수 0(첫 번째 GPU), 없으면 문자열 "mps" 또는 "cpu". ultralytics는 이 둘을 모두 받아들입니다. CUDA가 여러 장이면 1, 2로 고를 수 있지만 여기선 0번만.

🎛️ 장치 선택 시뮬레이터

직접 눌러보기
반환값 → 0

CUDA가 있으니 정수 0을 반환합니다. MPS는 검사하지 않아요.

🍭 5살 비유

“첫 번째 엘리베이터”는 0번이라고 부르는 약속이에요. 엘리베이터가 없으면 “에스컬레이터(mps)”, 그것도 없으면 “계단(cpu)”이라고 이름으로 알려 줍니다.

05 · read_truth()

YOLO 라벨 → 픽셀 xyxy

평가하려면 정답 박스가 픽셀 좌표로 필요합니다. 라벨 파일의 0~1 값을 이미지 크기로 곱해 되돌립니다.

common_yolo.py · 33–42행원문 그대로
def read_truth(image: Path) -> list[list[float]]:
    """YOLO 라벨(중심, 크기, 0~1)을 xyxy 픽셀 박스로 되돌린다."""

        boxes.append([(cx - w / 2) * width, (cy - h / 2) * height, (cx + w / 2) * width, (cy + h / 2) * height])
    return boxes

이미지 크기: Image.open(image).size → (width, height). 라벨 정규화를 풀려면 원본 크기가 필요.

라벨 경로: image.parent.parent / "labels" / stem.txt. 이미지가 valid/images/x.png라면 라벨은 valid/labels/x.txt.

줄마다: strip().splitlines(). 빈 줄 제거. 한 줄이 사람 한 명.

클래스 건너뛰기: line.split()[1:]로 0(person)을 뺀 나머지 4개만.

중심·크기 → xyxy: (cx ± w/2) * width, (cy ± h/2) * height.

반환: list[list[float]]. lab7은 COCO bbox로, lab8은 torch.tensor로 바꿔 씁니다.

🔬 정확히는

YOLO 라벨의 w, h는 “박스 너비/이미지 너비”, “박스 높이/이미지 높이”입니다. 그래서 되돌릴 때 각각 width, height를 곱합니다. 클래스 번호는 평가에서 모두 person(1)로 취급됩니다.

🧮

예시: 이미지 640×360, 라벨 0 0.5 0.5 0.25 0.5 → 중심 (320, 180), 크기 (160, 180) → xyxy [240, 90, 400, 270]. common 강의의 변환기와 같은 식이에요(방향만 반대).

⚠️ 함정
  • 라벨 파일이 없으면 read_text에서 FileNotFoundError. lab5 데이터셋이 온전해야 합니다.
  • 라벨이 빈 파일이면 boxes = []. 평가 코드가 빈 정답을 처리할 수 있어야 합니다.
  • 이미지 크기를 리사이즈 후 크기로 착각하면 박스가 어긋납니다. 여기선 원본 크기를 씁니다.
  • 클래스가 person 하나라는 전제. 다중 클래스면 [1:]만으로는 부족합니다.

def coco_view(model: YOLO, device: int | str) -> None:
    """같은 모델을 pycocotools(COCO 공식 평가 코드)로 다시 잰다."""
    images, annotations, detections = [], [], []
    for image_id, path in enumerate(valid_images(), start=1):
        result = model.predict(str(path), imgsz=IMAGE_SIZE, conf=EVAL_CONF, device=device, verbose=False)[0]
        height, width = result.orig_shape
        images.append({"id": image_id, "file_name": path.name, "width": width, "height": height})
        for x1, y1, x2, y2 in read_truth(path):
            annotations.append({"id": len(annotations) + 1, "image_id": image_id, "category_id": 1,
                                "bbox": [x1, y1, x2 - x1, y2 - y1], "area": (x2 - x1) * (y2 - y1), "iscrowd": 0})
        for (x1, y1, x2, y2), score in zip(result.boxes.xyxy.tolist(), result.boxes.conf.tolist()):
            detections.append({"image_id": image_id, "category_id": 1, "bbox": [x1, y1, x2 - x1, y2 - y1], "score": score})
    with tempfile.NamedTemporaryFile("w", suffix=".json", delete=False) as f:
        json.dump({"images": images, "annotations": annotations, "categories": [{"id": 1, "name": "person"}]}, f)
    truth = COCO(f.name)
    evaluator = COCOeval(truth, truth.loadRes(detections), "bbox")
    evaluator.evaluate()
    evaluator.accumulate()
    evaluator.summarize()
    print(f"pycocotools  AP50 {evaluator.stats[1]:.3f} / AP50-95 {evaluator.stats[0]:.3f} / 예측 {len(detections)}개, 정답 {len(annotations)}명")
    sizes = sorted((a["bbox"][3] for a in annotations))
    print(f"정답 박스 높이(px): 가장 작은 {sizes[0]:.0f}, 가운데 {sizes[len(sizes) // 2]:.0f}, 가장 큰 {sizes[-1]:.0f}")

낮은 conf로 전부 수집: EVAL_CONF=0.001. AP는 “점수 순으로 늘어놓은 전체 목록”이 필요합니다. 높은 conf만 남기면 곡선이 잘려요.

COCO 형식: 정답은 bbox=[x, y, w, h], area, iscrowd=0. 이미지 크기는 result.orig_shape에서 (height, width) 순서.

임시 JSON: NamedTemporaryFile(delete=False)로 COCO가 읽을 파일을 만듭니다. Windows에서 COCO가 다시 열 수 있도록 delete=False.

평가 3단: evaluate() → accumulate() → summarize(). 공식 COCO 절차.

비교: stats[1]=AP50, stats[0]=AP50-95. ultralytics와 값이 비슷한지 확인.

크기 분포: 정답 박스 높이의 최소/중앙/최대. 작은 사람이 많은지 감을 잡음.

🔬 정확히는 — AP와 mAP

AP는 precision-recall 곡선 아래 면적입니다. “점수를 낮춰 가며 더 많이 찾을수록, 정밀도가 얼마나 버티는가”를 하나의 숫자로 만든 것. mAP는 클래스별 AP의 평균(여기선 person 1개라 AP=mAP). IoU 기준을 올리면 “같은 사람”으로 인정하는 조건이 엄격해져 AP가 내려갑니다.

⚠️ 함정
  • box.px는 곡선의 conf 배열, p_curve[0]는 person 클래스. 클래스가 여러 개면 인덱스를 맞춰야 합니다.
  • searchsorted(box.px, conf)는 “가장 가까운 오른쪽” 위치를 찾습니다. 정확한 conf 지점이 아닐 수 있어요.
  • pycocotools는 bbox를 xywh로 받습니다. xyxy를 그대로 넣으면 엉뚱한 박스가 됩니다.

MATCH_IOU = 0.5     # 이 이상 겹치면 맞음
NEAR_IOU = 0.1      # 맞음은 아니어도 이 이상 겹치면 '위치 어긋남', 아래면 '배경 오탐'
CONFS = (0.25, 0.5, 0.646)   # 0.646은 lab7에서 F1이 가장 높던 conf
SMALL, MEDIUM = 32 * 32, 96 * 96   # COCO의 크기 구분(넓이, 픽셀²)


def size_name(box: list[float]) -> str:
    area = (box[2] - box[0]) * (box[3] - box[1])
    return "작음" if area < SMALL else "중간" if area < MEDIUM else "큼"


def classify(pred: torch.Tensor, truth: torch.Tensor) -> tuple[Counter, list[int]]:
    """점수 순으로 정답과 짝짓는다. 한 정답에는 예측 하나만. 남은 예측은 오류 종류로, 남은 정답은 놓침으로."""
    kinds: Counter = Counter()
    matched = [False] * len(truth)
    ious = box_iou(pred, truth) if len(pred) and len(truth) else torch.zeros(len(pred), len(truth))
    for i in range(len(pred)):   # pred는 이미 점수 내림차순
        best = int(ious[i].argmax()) if len(truth) else -1
        best_iou = float(ious[i, best]) if len(truth) else 0.0
        if best_iou >= MATCH_IOU and not matched[best]:
            matched[best] = True
            kinds["맞음"] += 1
        elif best_iou >= MATCH_IOU:
            kinds["중복"] += 1          # 이미 짝지어진 정답에 또 낸 박스: NMS가 못 지운 것
        elif best_iou >= NEAR_IOU:
            kinds["위치 어긋남"] += 1   # 사람 근처지만 박스가 덜 맞음
        else:
            kinds["배경 오탐"] += 1     # 정답 사람과 거의 안 겹침(라벨 없는 사람일 수도)
    return kinds, [k for k, m in enumerate(matched) if not m]

IoU 표: box_iou(pred, truth) → (예측 수, 정답 수). 예측은 ultralytics가 점수 내림차순으로 줍니다.

가장 겹치는 정답: argmax(). 정답이 없으면 -1, IoU 0.

맞음: IoU ≥ 0.5이고 그 정답이 아직 짝이 없을 때. 정답에 matched 표시.

중복: IoU ≥ 0.5인데 정답이 이미 짝지어짐. NMS가 못 지운 박스.

위치 어긋남: 0.1 ≤ IoU < 0.5. 사람 근처지만 박스가 덜 맞음.

배경 오탐: IoU < 0.1. 라벨 없는 사람일 수도 있음(데이터의 한계).

놓침: 끝까지 matched=False인 정답 인덱스. 크기별로 셈.

def letterbox(path: Path) -> tuple[np.ndarray, float, tuple[int, int]]:
    """긴 변을 416에 맞춰 줄이고, 남는 곳을 가운데 정렬로 회색으로 채운다(ultralytics와 같은 cv2 방식)."""
    bgr = cv2.imread(str(path))
    height, width = bgr.shape[:2]
    scale = IMAGE_SIZE / max(width, height)
    new_w, new_h = round(width * scale), round(height * scale)
    left, top = round((IMAGE_SIZE - new_w) / 2 - 0.1), round((IMAGE_SIZE - new_h) / 2 - 0.1)
    canvas = np.full((IMAGE_SIZE, IMAGE_SIZE, 3), PAD_VALUE, dtype=np.uint8)
    canvas[top:top + new_h, left:left + new_w] = cv2.resize(bgr, (new_w, new_h), interpolation=cv2.INTER_LINEAR)
    rgb = canvas[..., ::-1]   # 모델은 RGB를 받는다
    array = np.ascontiguousarray(rgb.transpose(2, 0, 1)[None], dtype=np.float32) / 255.0   # (1, 3, 416, 416), 0~1
    return array, scale, (left, top)

BGR로 읽기: OpenCV 기본. height, width 순서.

긴 변 기준 축소: scale = 416 / max(w,h). 가로세로 비율 유지.

가운데 정렬: 남는 공간의 절반씩. -0.1은 반올림 보정(ultralytics와 맞추기).

회색 캔버스: 114로 채우고, 축소한 이미지를 붙임.

RGB로: canvas[..., ::-1]. 모델은 RGB를 기대.

텐서 모양: HWC → CHW → 배치 추가 → (1,3,416,416), /255.

def decode(output: np.ndarray, scale: float, pad: tuple[float, float]) -> tuple[torch.Tensor, torch.Tensor]:
    """(1, 5, N) → 점수로 거르고, 중심·크기를 xyxy로, 패딩과 크기 조절을 되돌리고, NMS."""
    pred = torch.from_numpy(output[0]).T          # (N, 5): cx, cy, w, h, 사람 점수
    pred = pred[pred[:, 4] >= CONF]
    cx, cy, w, h = pred[:, 0], pred[:, 1], pred[:, 2], pred[:, 3]
    boxes = torch.stack([cx - w / 2, cy - h / 2, cx + w / 2, cy + h / 2], dim=1)
    boxes[:, [0, 2]] = (boxes[:, [0, 2]] - pad[0]) / scale
    boxes[:, [1, 3]] = (boxes[:, [1, 3]] - pad[1]) / scale
    keep = nms(boxes, pred[:, 4], NMS_IOU)
    return boxes[keep], pred[keep, 4]

"""7차시 실습: 틀린 것을 종류별로 센다 — 위치 어긋남, 중복, 배경 오탐, 놓침(크기별)."""
import sys
from collections import Counter

import torch
from torchvision.ops import box_iou
from ultralytics import YOLO

from common_yolo import BEST, IMAGE_SIZE, pick_device, read_truth, require_lab5, valid_images

MATCH_IOU = 0.5     # 이 이상 겹치면 맞음
NEAR_IOU = 0.1      # 맞음은 아니어도 이 이상 겹치면 '위치 어긋남', 아래면 '배경 오탐'
CONFS = (0.25, 0.5, 0.646)   # 0.646은 lab7에서 F1이 가장 높던 conf
SMALL, MEDIUM = 32 * 32, 96 * 96   # COCO의 크기 구분(넓이, 픽셀²)


def size_name(box: list[float]) -> str:
    area = (box[2] - box[0]) * (box[3] - box[1])
    return "작음" if area < SMALL else "중간" if area < MEDIUM else "큼"


def classify(pred: torch.Tensor, truth: torch.Tensor) -> tuple[Counter, list[int]]:
    """점수 순으로 정답과 짝짓는다. 한 정답에는 예측 하나만. 남은 예측은 오류 종류로, 남은 정답은 놓침으로."""
    kinds: Counter = Counter()
    matched = [False] * len(truth)
    ious = box_iou(pred, truth) if len(pred) and len(truth) else torch.zeros(len(pred), len(truth))
    for i in range(len(pred)):   # pred는 이미 점수 내림차순
        best = int(ious[i].argmax()) if len(truth) else -1
        best_iou = float(ious[i, best]) if len(truth) else 0.0
        if best_iou >= MATCH_IOU and not matched[best]:
            matched[best] = True
            kinds["맞음"] += 1
        elif best_iou >= MATCH_IOU:
            kinds["중복"] += 1          # 이미 짝지어진 정답에 또 낸 박스: NMS가 못 지운 것
        elif best_iou >= NEAR_IOU:
            kinds["위치 어긋남"] += 1   # 사람 근처지만 박스가 덜 맞음
        else:
            kinds["배경 오탐"] += 1     # 정답 사람과 거의 안 겹침(라벨 없는 사람일 수도)
    return kinds, [k for k, m in enumerate(matched) if not m]


def main() -> int:
    require_lab5()
    device = pick_device()
    model = YOLO(str(BEST))
    images = valid_images()
    truth_by_image = {p: read_truth(p) for p in images}
    all_truth = [b for boxes in truth_by_image.values() for b in boxes]
    print("정답 크기:", dict(Counter(size_name(b) for b in all_truth)), "합계", len(all_truth))
    for conf in CONFS:
        total, missed_sizes, worst = Counter(), Counter(), []
        for path in images:
            result = model.predict(str(path), imgsz=IMAGE_SIZE, conf=conf, device=device, verbose=False)[0]
            truth = torch.tensor(truth_by_image[path]).reshape(-1, 4)
            kinds, missed = classify(result.boxes.xyxy.cpu(), truth)
            total += kinds
            missed_sizes.update(size_name(truth_by_image[path][k]) for k in missed)
            errors = len(missed) + sum(v for k, v in kinds.items() if k != "맞음")
            worst.append((errors, path.name, len(missed), len(result.boxes), len(truth)))
        n_missed = sum(missed_sizes.values())
        print(f"conf {conf}: {dict(total)}, 놓침 {n_missed} {dict(missed_sizes)}")
        top = sorted(worst, reverse=True)[:3]
        print("   오류가 많은 사진:", ", ".join(f"{name}(오류 {e}, 놓침 {m}, 탐지 {d}/정답 {t})" for e, name, m, d, t in top))
    return 0


if __name__ == "__main__":
    sys.exit(main())

"""9차시 실습: best.pt를 ONNX로 내보내고, ultralytics 없이 onnxruntime만으로 박스를 낸다.

출력 (1, 5, 3549)을 손으로 풀어 본다: 3549 = 52² + 26² + 13² 칸, 5 = 박스 4 + 사람 점수 1(앵커 없음, objectness 없음).
"""
import sys
import time
from pathlib import Path

import cv2
import numpy as np
import onnxruntime as ort
import torch
from torchvision.ops import box_iou, nms
from ultralytics import YOLO

from common_yolo import BEST, IMAGE_SIZE, pick_device, require_lab5, valid_images

CONF = 0.5
NMS_IOU = 0.7      # ultralytics 기본값과 같게
PAD_VALUE = 114    # ultralytics가 빈 곳을 채우는 회색


def letterbox(path: Path) -> tuple[np.ndarray, float, tuple[int, int]]:
    """긴 변을 416에 맞춰 줄이고, 남는 곳을 가운데 정렬로 회색으로 채운다(ultralytics와 같은 cv2 방식)."""
    bgr = cv2.imread(str(path))
    height, width = bgr.shape[:2]
    scale = IMAGE_SIZE / max(width, height)
    new_w, new_h = round(width * scale), round(height * scale)
    left, top = round((IMAGE_SIZE - new_w) / 2 - 0.1), round((IMAGE_SIZE - new_h) / 2 - 0.1)
    canvas = np.full((IMAGE_SIZE, IMAGE_SIZE, 3), PAD_VALUE, dtype=np.uint8)
    canvas[top:top + new_h, left:left + new_w] = cv2.resize(bgr, (new_w, new_h), interpolation=cv2.INTER_LINEAR)
    rgb = canvas[..., ::-1]   # 모델은 RGB를 받는다
    array = np.ascontiguousarray(rgb.transpose(2, 0, 1)[None], dtype=np.float32) / 255.0   # (1, 3, 416, 416), 0~1
    return array, scale, (left, top)


def decode(output: np.ndarray, scale: float, pad: tuple[float, float]) -> tuple[torch.Tensor, torch.Tensor]:
    """(1, 5, N) → 점수로 거르고, 중심·크기를 xyxy로, 패딩과 크기 조절을 되돌리고, NMS."""
    pred = torch.from_numpy(output[0]).T          # (N, 5): cx, cy, w, h, 사람 점수
    pred = pred[pred[:, 4] >= CONF]
    cx, cy, w, h = pred[:, 0], pred[:, 1], pred[:, 2], pred[:, 3]
    boxes = torch.stack([cx - w / 2, cy - h / 2, cx + w / 2, cy + h / 2], dim=1)
    boxes[:, [0, 2]] = (boxes[:, [0, 2]] - pad[0]) / scale
    boxes[:, [1, 3]] = (boxes[:, [1, 3]] - pad[1]) / scale
    keep = nms(boxes, pred[:, 4], NMS_IOU)
    return boxes[keep], pred[keep, 4]


def main() -> int:
    require_lab5()
    onnx_path = Path(YOLO(str(BEST)).export(format="onnx", imgsz=IMAGE_SIZE, dynamic=False, simplify=True, verbose=False))
    # best.pt는 가중치를 float16으로, ONNX는 float32로 저장해서 크기가 두 배쯤 된다
    print(f"파일 크기: best.pt {BEST.stat().st_size / 2**20:.1f}MiB → {onnx_path.name} {onnx_path.stat().st_size / 2**20:.1f}MiB")
    session = ort.InferenceSession(str(onnx_path), providers=["CPUExecutionProvider"])
    inp, out = session.get_inputs()[0], session.get_outputs()[0]
    print(f"입력 {inp.name} {inp.shape} / 출력 {out.name} {out.shape}")

    reference = YOLO(str(onnx_path), task="detect")   # 같은 ONNX를 ultralytics가 돌린 결과와 견준다
    pt_model = YOLO(str(BEST))
    total_mine = total_ref = total_pt = 0
    shifts, unmatched = [], 0
    for path in valid_images():
        array, scale, pad = letterbox(path)
        boxes, _ = decode(session.run(None, {inp.name: array})[0], scale, pad)
        ref = reference.predict(str(path), imgsz=IMAGE_SIZE, conf=CONF, iou=NMS_IOU, device="cpu", verbose=False)[0].boxes.xyxy.cpu()
        pt = pt_model.predict(str(path), imgsz=IMAGE_SIZE, conf=CONF, iou=NMS_IOU, device=pick_device(), verbose=False)[0].boxes
        total_mine, total_ref, total_pt = total_mine + len(boxes), total_ref + len(ref), total_pt + len(pt)
        if len(boxes) and len(ref):
            # 내 박스마다 가장 많이 겹치는 ultralytics 박스를 찾아 꼭짓점 차이(픽셀)를 잰다
            best_iou, nearest = box_iou(boxes, ref).max(dim=1)
            same = best_iou >= 0.9
            shifts += (boxes[same] - ref[nearest[same]]).abs().amax(dim=1).tolist()
            unmatched += int((~same).sum())
        else:
            unmatched += len(boxes)
    print(f"검증 34장, conf {CONF}: 직접 푼 ONNX {total_mine}개 / ultralytics의 ONNX {total_ref}개 / ultralytics의 best.pt {total_pt}개")
    print(f"짝지은 박스 {len(shifts)}개의 꼭짓점 차이: 가장 큰 {max(shifts):.3f}px, 평균 {np.mean(shifts):.4f}px / 짝 없는 박스 {unmatched}개")

    array, _, _ = letterbox(valid_images()[0])
    for _ in range(3):
        session.run(None, {inp.name: array})   # 처음 몇 번은 준비 시간이 섞인다
    start = time.perf_counter()
    for _ in range(50):
        session.run(None, {inp.name: array})
    print(f"onnxruntime CPU 추론만: {(time.perf_counter() - start) / 50 * 1000:.1f}ms/장 (기본 설정)")
    return 0


if __name__ == "__main__":
    sys.exit(main())

"""10차시 실습: 빠르게 만들고, 무엇을 잃었는지 잰다 — 입력 크기와 int8 양자화.

def latency_ms(onnx_path: Path, size: int) -> float:

    lab10_onnx.IMAGE_SIZE = size   # 같은 전처리를 크기만 바꿔 쓴다

def accuracy(onnx_path: Path, size: int) -> tuple[float, float]:

class Calibration(CalibrationDataReader):
    """int8 범위를 정할 때 쓸 입력을 하나씩 내준다."""

    def __init__(self, input_name: str) -> None:
        paths = sorted((YOLO_ROOT / "train" / "images").glob("*.png"))[:CALIB_IMAGES]
        self.items = iter([{input_name: letterbox(p)[0]} for p in paths])

    def get_next(self) -> dict | None:
        return next(self.items, None)

    for size in SIZES:

                    op_types_to_quantize=None if QUANTIZE_ALL else ["Conv"])
    ms = latency_ms(int8, 416)
    m50, m = accuracy(int8, 416)
    label = "int8 전부 416" if QUANTIZE_ALL else "int8 합성곱만 416"
    print(f"{label:22s}{int8.stat().st_size / 2**20:10.1f}{ms:11.1f}{m50:8.3f}{m:10.3f}")
    return 0


if __name__ == "__main__":
    sys.exit(main())

13 · 용어 사전

        
막히면 여기로

      

      
best.pt
ultralytics 학습이 검증 지표 기준으로 고른 최고 체크포인트. 경로는 runs/person/weights/best.pt.

      
data.yaml
데이터셋 설정. path, train, val, nc, names. require_lab5가 존재를 확인합니다.

      
SystemExit
프로그램 종료를 알리는 예외(BaseException 계열). except Exception으로는 잡히지 않습니다.

      
AP / mAP
AP는 precision-recall 곡선 아래 면적. mAP는 클래스 평균. mAP50은 IoU 0.5, mAP50-95는 IoU 0.5~0.95 평균.

      
Precision / Recall / F1
정밀도 = 맞힌 것 / 낸 것. 재현율 = 맞힌 것 / 정답. F1 = 2PR/(P+R). conf를 올리면 정밀도↑, 재현율↓ 경향.

      
IoU
두 박스의 교집합 넓이 / 합집합 넓이. 1에 가까울수록 겹침. 맞음 판정 기준으로 0.5를 자주 씁니다.

      
NMS
Non-Maximum Suppression. 같은 물체에 겹친 박스 중 점수 높은 것만 남기고 나머지를 지웁니다. lab10은 IoU 0.7.

      
pycocotools
COCO 공식 평가 코드. bbox는 [x, y, w, h] 형식입니다. COCOeval로 AP를 계산.

      
letterbox
