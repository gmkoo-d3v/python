03 · ssl_context()

“이 사이트 믿어도 돼요?”를 확인하는 방법

HTTPS 다운로드에서 서버 인증서를 검사할 때, 어떤 인증서 목록을 쓸지 고릅니다. 학원·회사 네트워크에서 자주 막히는 지점이에요.

common.py · 22–38행원문 그대로
def ssl_context() -> ssl.SSLContext:
    """인증서 목록을 고릅니다. 파이썬 기본 목록만으로는 이 서버의 인증서를 확인하지 못하는 컴퓨터가 있습니다.

    1) truststore가 깔려 있으면 운영체제의 인증서 저장소를 그대로 씁니다(학원·회사 보안 프록시 인증서도 포함).
    2) 없으면 certifi(ultralytics와 함께 깔림)의 목록을 씁니다. 서버 인증서의 뿌리(emSign Root CA - G1)가 들어 있습니다.
    3) 둘 다 없으면 파이썬 기본값.
    """
    try:
        import truststore
        return truststore.SSLContext(ssl.PROTOCOL_TLS_CLIENT)
    except ImportError:
        pass
    try:
        import certifi
        return ssl.create_default_context(cafile=certifi.where())
    except ImportError:
        return ssl.create_default_context()

1순위 truststore: 설치돼 있으면 운영체제(Windows/macOS)의 인증서 저장소를 그대로 씁니다. 회사·학원의 보안 프록시가 끼어든 인증서도 여기 들어 있어요.

2순위 certifi: truststore가 없으면 certifi의 CA 묶음. ultralytics와 함께 설치되는 경우가 많고, Penn 서버의 뿌리 인증서(emSign Root CA - G1)가 들어 있습니다.

3순위 파이썬 기본: 둘 다 없으면 ssl.create_default_context(). 가장 보수적이지만, 이 서버에서는 실패하는 컴퓨터가 있습니다.

⚠️ 함정

except ImportError만 잡습니다. truststore가 설치돼 있는데 초기화 중 다른 에러가 나면 그대로 올라갑니다. 또 인증서 검증 실패는 여기서 처리하지 않고, 다음 함수 penn_root()에서 친절한 안내로 바꿔 줍니다.

🍭 5살 비유

낯선 사람이 “나 은행 직원이야”라고 할 때, 신분증 목록을 보고 확인하는 거예요. 우리 집 목록(OS), 인터넷 공용 목록(certifi), 기본 목록(파이썬) 순서로 찾아봅니다.

04 · penn_root()

없으면 받고, 있으면 바로 돌려주기

데이터 폴더가 이미 있으면 즉시 반환. 없으면 zip을 내려받아 풉니다. 실패했을 때의 뒷정리까지 포함합니다.

common.py · 41–64행원문 그대로
def penn_root() -> Path:
    """Penn-Fudan 폴더를 돌려줍니다. 없으면 내려받아 풉니다."""
    target = DATA_ROOT / "PennFudanPed"
    if target.exists():
        return target
    DATA_ROOT.mkdir(parents=True, exist_ok=True)
    zip_path = DATA_ROOT / "PennFudanPed.zip"
    try:
        with urllib.request.urlopen(PENN_URL, timeout=DOWNLOAD_TIMEOUT_SEC, context=ssl_context()) as response, open(zip_path, "wb") as f:
            shutil.copyfileobj(response, f)
    except urllib.error.URLError as error:
        zip_path.unlink(missing_ok=True)   # 반쯤 받은 파일이 남으면 다음 실행에서 깨진 zip을 풀게 된다
        if not isinstance(error.reason, ssl.SSLCertVerificationError):
            raise
        raise SystemExit(
            f"인증서 확인에 실패해 데이터를 받지 못했습니다: {error.reason}\n"
            "학원·회사 네트워크의 보안 장비가 인증서를 바꿔 끼우는 경우가 많습니다. 둘 중 하나를 하세요.\n"
            "  1) 명령에 --with truststore를 더해 다시 실행합니다(운영체제 인증서 저장소를 씁니다).\n"
            f"  2) 브라우저로 {PENN_URL} 을 받아 {DATA_ROOT} 에 풀고 다시 실행합니다.\n"
            "     다른 곳에 풀었다면 PENN_DATA_ROOT에 PennFudanPed 폴더의 상위 폴더를 알려 줍니다."
        ) from error
    with zipfile.ZipFile(zip_path) as z:
        z.extractall(DATA_ROOT)
    return target

이미 있나? DATA_ROOT / "PennFudanPed"가 존재하면 바로 반환. 내용이 온전한지는 검사하지 않습니다.

부모 폴더 만들기: mkdir(parents=True, exist_ok=True). 없으면 만들고, 있어도 에러 없음.

스트리밍 다운로드: urlopen(..., timeout=180, context=ssl_context()) + shutil.copyfileobj. 전체를 메모리에 올리지 않고 조금씩 파일로 복사합니다.

실패 정리: URLError면 반쯤 받은 zip을 unlink(missing_ok=True)로 삭제. 다음 실행에서 깨진 zip을 푸는 사고를 막아요.

SSL 실패만 친절하게: error.reason이 SSLCertVerificationError이면 SystemExit로 안내문을 보여 줍니다. 다른 네트워크 에러는 그대로 다시 던짐(raise).

압축 해제: ZipFile(...).extractall(DATA_ROOT) 후 target 반환. zip 파일 자체는 남겨 둡니다.

⚠️ 함정
  • 폴더가 존재하기만 하면 다운로드를 건너뜁니다. 중간에 깨진 데이터가 있으면 직접 지우고 다시 실행해야 해요.
  • zip을 풀 때 경로 검증(zip slip 방지)을 하지 않습니다. 신뢰하는 원본 URL에서만 받는 전제.
  • 다운로드가 180초 안에 끝나야 합니다. 아주 느린 회선이면 DOWNLOAD_TIMEOUT_SEC를 늘리세요.
  • 인증서 오류 안내문의 --with truststore는 “uv로 실행할 때 패키지를 추가”하는 옵션입니다. 이미 의존성에 들어 있으면 그냥 다시 실행해도 됩니다.
🍭 5살 비유

장난감 상자가 이미 방에 있으면 그냥 꺼내 놀고, 없으면 택배를 시켜요. 택배가 오다가 깨지면 반쯤 온 상자를 버리고, “공항 보안 검색 때문에 못 받았어요”라고 알려 주는 거죠.

05 · mask_to_boxes()

사람 모양 스티커 → 네모 박스

Penn-Fudan은 사람마다 인스턴스 마스크를 줍니다. 마스크의 픽셀 좌표에서 가장 작은/큰 x·y를 찾아 xyxy 박스로 바꿉니다.

common.py · 67–74행원문 그대로
def mask_to_boxes(mask_path: Path) -> list[list[int]]:
    """인스턴스 마스크에서 사람별 xyxy 박스를 구합니다. 노트북 1.4절과 같은 규칙입니다."""
    mask = np.array(Image.open(mask_path))
    boxes = []
    for object_id in np.unique(mask)[1:]:   # 0은 배경
        ys, xs = np.where(mask == object_id)
        boxes.append([int(xs.min()), int(ys.min()), int(xs.max()) + 1, int(ys.max()) + 1])
    return boxes

마스크 읽기: 마스크 PNG는 픽셀마다 “사람 번호”가 적힌 2D 배열입니다. 0은 배경, 1·2·3…은 각 사람.

배경 빼기: np.unique(mask)[1:]. 정렬된 고유값에서 0만 건너뜁니다.

그 사람 픽셀 찾기: np.where(mask == object_id) → ys, xs.

박스로: xs.min(), ys.min(), xs.max()+1, ys.max()+1. +1은 “끝 좌표는 포함하지 않는다”는 관례(x2, y2는 exclusive) 때문입니다.

정수로: NumPy 정수를 파이썬 int로 바꿔 JSON/출력에 안전하게.

🔬 정확히는 — +1의 의미

픽셀 인덱스가 10부터 19까지 있다면, 실제로 덮는 구간은 [10, 20)입니다. 그래서 max + 1을 씁니다. x2 - x1이 픽셀 폭이 되고, 자르기(crop)나 IoU 계산과 잘 맞아요. 반대로 max를 그대로 쓰면 폭이 1픽셀 작아집니다.

🧩

사람이 가장자리에서 잘렸다면? 마스크에 보이는 부분만 있으므로 박스도 보이는 부분 기준입니다. lab5는 그대로 학습에 쓰고, lab20은 “화면 가장자리에 잘린 사람”을 따로 걸러 냅니다.

🍭 5살 비유

사람 모양으로 오려 붙인 스티커가 있어요. 스티커의 제일 왼쪽·위·오른쪽·아래 점을 찾아 네모 상자를 그리는 거예요. 스티커 모양이 삐죽삐죽해도 상자는 반듯합니다.

06 · load_split()

170장을 136 : 34로

모든 사진과 박스를 읽고, 고정된 시드로 섞은 뒤 앞 80%를 학습, 뒤 20%를 검증으로 돌려줍니다.

common.py · 77–90행원문 그대로
def load_split() -> tuple[list[dict], list[dict]]:
    """샘플을 읽고 노트북과 같은 난수로 섞어 8:2로 나눕니다."""
    root = penn_root()
    samples = []
    for image_path in sorted((root / "PNGImages").glob("*.png")):
        with Image.open(image_path) as image:
            width, height = image.size
        boxes = mask_to_boxes(root / "PedMasks" / f"{image_path.stem}_mask.png")
        samples.append({"path": image_path, "width": width, "height": height, "boxes": boxes})
    shuffled = samples.copy()
    random.Random(SPLIT_SEED).shuffle(shuffled)
    num_train = int(len(shuffled) * TRAIN_RATIO)
    return shuffled[:num_train], shuffled[num_train:]

데이터 확보: penn_root()가 폴더를 보장합니다.

정렬된 목록: sorted(...glob("*.png")). 파일 시스템 순서에 흔들리지 않게 이름순으로.

크기 읽기: Image.open(...).size는 (width, height) 순서. 나중에 YOLO 라벨을 정규화할 때 필요합니다.

마스크 경로: PedMasks/<stem>_mask.png. 사진 이름에서 확장자만 뗀 stem을 씁니다.

샘플 dict: path, width, height, boxes. lab5와 lab9가 그대로 재사용하는 형식.

섞기: random.Random(SPLIT_SEED).shuffle(...). 전역 random 상태를 건드리지 않는 지역 RNG.

8:2 자르기: int(170 * 0.8) = 136 학습, 나머지 34 검증. copy() 덕분에 원래 samples 순서는 보존.

🔀 8:2 나눔 시뮬레이터

170장

점 하나가 사진 한 장입니다. 136장은 학습(청록), 34장은 검증(코랄). “섞기”를 누르면 seed 1729로 위치가 다시 섞입니다.

train 136 valid 34
정렬된 170장을 섞은 뒤 앞 136장을 train으로.
⚠️ 함정
  • 학습/검증을 나누는 시드가 두 군데 있습니다. common.SPLIT_SEED(데이터 8:2)와 lab5.SEED=1729(모델 학습). 값은 같지만 역할은 다릅니다.
  • random.Random(seed)는 인스턴스라 전역 난수와 분리됩니다. 다른 코드가 random.seed()를 바꿔도 이 나눔은 흔들리지 않아요.
  • 사진을 열어 크기만 읽고 닫습니다(with). 박스는 마스크에서 나오므로 사진 픽셀을 메모리에 들고 있지 않습니다.
  • 170장이 아닌 데이터로 바꾸면 int(n * 0.8)이라 80%가 조금 모자랄 수 있습니다(내림).
  • train/valid의 순서는 “섞인 순서”입니다. 파일명 정렬 순서가 아닙니다.
🍭 5살 비유

카드 170장을 7번 마법으로 섞고, 앞에서 136장은 “연습 카드”, 뒤 34장은 “시험 카드”로 나누는 거예요. 내일 다시 해도 7번 마법이라 똑같이 나뉩니다.

07 · lab5_yolo11.py

공용 데이터를 YOLO 형식으로, 그리고 전이학습

common.py가 만든 dict 목록을 YOLO가 읽는 폴더 구조와 라벨 파일로 바꾸고, COCO로 학습된 YOLO11s를 사람 탐지에 맞게 다시 학습합니다.

lab5_yolo11.py · 25–33행원문 그대로

def to_yolo_label(box: list[int], width: int, height: int) -> tuple[float, float, float, float]:
    """xyxy 픽셀 박스를 YOLO 형식(중심과 크기, 0~1)으로 바꿉니다."""
    x1, y1, x2, y2 = box
    return ((x1 + x2) / 2 / width, (y1 + y2) / 2 / height, (x2 - x1) / width, (y2 - y1) / height)


def yolo_to_xyxy(label: list[float], width: int, height: int) -> list[float]:
    """YOLO 형식(0~1)을 xyxy 픽셀 박스로 되돌립니다."""
    center_x, center_y, w, h = label
    return [(center_x - w / 2) * width, (center_y - h / 2) * height, (center_x + w / 2) * width, (center_y + h / 2) * height]
🔬 정확히는 — 두 가지 표기

xyxy는 “왼쪽 위, 오른쪽 아래” 픽셀 좌표. YOLO는 “중심 x, 중심 y, 너비, 높이”를 이미지 크기로 나눈 0~1 값입니다. 클래스 번호는 라벨 줄 맨 앞에 따로 붙습니다(0=person). 정규화 덕분에 이미지 크기가 달라도 같은 라벨을 쓸 수 있어요.

def write_dataset(train: list[dict], valid: list[dict]) -> Path:
    """images/labels 폴더와 data.yaml을 만듭니다. 라벨 폴더는 images를 labels로 바꾼 경로여야 한다."""
    shutil.rmtree(YOLO_ROOT, ignore_errors=True)   # 이전 실행의 파일이 섞이지 않게 한다
    for split, split_samples in (("train", train), ("valid", valid)):
        (YOLO_ROOT / split / "images").mkdir(parents=True)
        (YOLO_ROOT / split / "labels").mkdir(parents=True)
        for s in split_samples:
            shutil.copy(s["path"], YOLO_ROOT / split / "images" / s["path"].name)
            rows = [" ".join(["0"] + [f"{v:.6f}" for v in to_yolo_label(b, s["width"], s["height"])]) for b in s["boxes"]]
            (YOLO_ROOT / split / "labels" / f"{s['path'].stem}.txt").write_text("\n".join(rows) + "\n")
    config = {"path": str(YOLO_ROOT), "train": "train/images", "val": "valid/images", "nc": 1, "names": ["person"]}
    config_path = YOLO_ROOT / "data.yaml"
    config_path.write_text(yaml.safe_dump(config))
    return config_path

    print("되돌린 박스가 원래 박스와 1픽셀 이내: 통과")

    sample_image = str(YOLO_ROOT / "valid" / "images" / valid[0]["path"].name)
    result = pretrained(sample_image, verbose=False)[0]
    names = [result.names[int(c)] for c in result.boxes.cls]
    print(f"사전학습으로 {valid[0]['path'].name}: {dict((n, names.count(n)) for n in sorted(set(names)))} / 정답 사람 {len(valid[0]['boxes'])}명")

    # 3) 전이학습
    start = time.time()
    model = YOLO(WEIGHTS)
    model.add_callback("on_fit_epoch_end", print_progress)
    model.train(data=str(config_path), imgsz=IMAGE_SIZE, batch=BATCH, epochs=EPOCHS, device=device,
                project=str(RUN_DIR), name="person", exist_ok=True, seed=SEED, plots=False)
    print(f"학습 시간: {time.time() - start:.0f}초 ({EPOCHS} epoch)")

    # 4) best.pt를 명시적으로 불러 평가
    best = YOLO(str(RUN_DIR / "person" / "weights" / "best.pt"))

    print(f"best.pt  mAP50 = {metrics.box.map50:.3f} / mAP50-95 = {metrics.box.map:.3f} / 클래스 {best.names}")
    with open(RUN_DIR / "person" / "results.csv") as f:
        rows = list(csv.DictReader(f))
    best_row = max(rows, key=lambda r: float(r["metrics/mAP50-95(B)"].strip()))
    print("가장 좋은 epoch:", int(float(best_row["epoch"])))

    # 5) 기준 점수와 탐지 수
    counts = {conf: len(best.predict(sample_image, conf=conf, verbose=False)[0].boxes) for conf in (0.25, 0.5, 0.9)}

    assert counts[0.25] >= counts[0.5] >= counts[0.9]   # 기준을 높이면 줄어들기만 한다
    total = sum(len(r.boxes) for r in best.predict([str(YOLO_ROOT / "valid" / "images" / s["path"].name) for s in valid], conf=0.5, verbose=False, stream=True))

def ssl_context() -> ssl.SSLContext:
    """인증서 목록을 고릅니다. 파이썬 기본 목록만으로는 이 서버의 인증서를 확인하지 못하는 컴퓨터가 있습니다.

    1) truststore가 깔려 있으면 운영체제의 인증서 저장소를 그대로 씁니다(학원·회사 보안 프록시 인증서도 포함).
    2) 없으면 certifi(ultralytics와 함께 깔림)의 목록을 씁니다. 서버 인증서의 뿌리(emSign Root CA - G1)가 들어 있습니다.
    3) 둘 다 없으면 파이썬 기본값.
    """
    try:
        import truststore
        return truststore.SSLContext(ssl.PROTOCOL_TLS_CLIENT)
    except ImportError:
        pass
    try:
        import certifi
        return ssl.create_default_context(cafile=certifi.where())
    except ImportError:
        return ssl.create_default_context()


def penn_root() -> Path:
    """Penn-Fudan 폴더를 돌려줍니다. 없으면 내려받아 풉니다."""
    target = DATA_ROOT / "PennFudanPed"
    if target.exists():
        return target
    DATA_ROOT.mkdir(parents=True, exist_ok=True)
    zip_path = DATA_ROOT / "PennFudanPed.zip"
    try:
        with urllib.request.urlopen(PENN_URL, timeout=DOWNLOAD_TIMEOUT_SEC, context=ssl_context()) as response, open(zip_path, "wb") as f:
            shutil.copyfileobj(response, f)
    except urllib.error.URLError as error:
        zip_path.unlink(missing_ok=True)   # 반쯤 받은 파일이 남으면 다음 실행에서 깨진 zip을 풀게 된다
        if not isinstance(error.reason, ssl.SSLCertVerificationError):
            raise
        raise SystemExit(
            f"인증서 확인에 실패해 데이터를 받지 못했습니다: {error.reason}\n"
            "학원·회사 네트워크의 보안 장비가 인증서를 바꿔 끼우는 경우가 많습니다. 둘 중 하나를 하세요.\n"
            "  1) 명령에 --with truststore를 더해 다시 실행합니다(운영체제 인증서 저장소를 씁니다).\n"
            f"  2) 브라우저로 {PENN_URL} 을 받아 {DATA_ROOT} 에 풀고 다시 실행합니다.\n"
            "     다른 곳에 풀었다면 PENN_DATA_ROOT에 PennFudanPed 폴더의 상위 폴더를 알려 줍니다."
        ) from error
    with zipfile.ZipFile(zip_path) as z:
        z.extractall(DATA_ROOT)
    return target


def mask_to_boxes(mask_path: Path) -> list[list[int]]:
    """인스턴스 마스크에서 사람별 xyxy 박스를 구합니다. 노트북 1.4절과 같은 규칙입니다."""
    mask = np.array(Image.open(mask_path))
    boxes = []
    for object_id in np.unique(mask)[1:]:   # 0은 배경
        ys, xs = np.where(mask == object_id)
        boxes.append([int(xs.min()), int(ys.min()), int(xs.max()) + 1, int(ys.max()) + 1])
    return boxes


def load_split() -> tuple[list[dict], list[dict]]:
    """샘플을 읽고 노트북과 같은 난수로 섞어 8:2로 나눕니다."""
    root = penn_root()
    samples = []
    for image_path in sorted((root / "PNGImages").glob("*.png")):
        with Image.open(image_path) as image:
            width, height = image.size
        boxes = mask_to_boxes(root / "PedMasks" / f"{image_path.stem}_mask.png")
        samples.append({"path": image_path, "width": width, "height": height, "boxes": boxes})
    shuffled = samples.copy()
    random.Random(SPLIT_SEED).shuffle(shuffled)
    num_train = int(len(shuffled) * TRAIN_RATIO)
    return shuffled[:num_train], shuffled[num_train:]

"""5차시 실습: ultralytics YOLO11로 사람 탐지 전이학습 (6강 노트북 5.4절, 실습 8).

라이선스: ultralytics는 AGPL-3.0이고, 약관상 직접 학습한 모델에도 적용됩니다.
이 파일은 교안 코드의 MIT 라이선스에서 제외하며 AGPL-3.0 조건을 따릅니다.
"""
import csv
import os
import shutil
import sys
import time
import warnings
from pathlib import Path

os.environ.setdefault("YOLO_VERBOSE", "False")   # import 전에 정해야 적용된다
# MPS에서 결정적 구현이 없다는 경고가 배치마다 나와 출력을 덮으므로 그것만 끈다
warnings.filterwarnings("ignore", message=".*does not have a deterministic implementation.*")

import torch
import yaml
from ultralytics import YOLO
from ultralytics.engine.trainer import BaseTrainer

from common import load_split

WEIGHTS = "yolo11s.pt"
IMAGE_SIZE = 416
BATCH = 16
EPOCHS = int(os.environ.get("YOLO_EPOCHS", "50"))   # 수업 시간이 짧으면 YOLO_EPOCHS=10
PRINT_EVERY = 10
SEED = 1729
HERE = Path(__file__).resolve().parent
YOLO_ROOT = HERE / "data" / "PennFudan_yolo"
RUN_DIR = HERE / "runs"


def to_yolo_label(box: list[int], width: int, height: int) -> tuple[float, float, float, float]:
    """xyxy 픽셀 박스를 YOLO 형식(중심과 크기, 0~1)으로 바꿉니다."""
    x1, y1, x2, y2 = box
    return ((x1 + x2) / 2 / width, (y1 + y2) / 2 / height, (x2 - x1) / width, (y2 - y1) / height)


def yolo_to_xyxy(label: list[float], width: int, height: int) -> list[float]:
    """YOLO 형식(0~1)을 xyxy 픽셀 박스로 되돌립니다."""
    center_x, center_y, w, h = label
    return [(center_x - w / 2) * width, (center_y - h / 2) * height, (center_x + w / 2) * width, (center_y + h / 2) * height]


def write_dataset(train: list[dict], valid: list[dict]) -> Path:
    """images/labels 폴더와 data.yaml을 만듭니다. 라벨 폴더는 images를 labels로 바꾼 경로여야 한다."""
    shutil.rmtree(YOLO_ROOT, ignore_errors=True)   # 이전 실행의 파일이 섞이지 않게 한다
    for split, split_samples in (("train", train), ("valid", valid)):
        (YOLO_ROOT / split / "images").mkdir(parents=True)
        (YOLO_ROOT / split / "labels").mkdir(parents=True)
        for s in split_samples:
            shutil.copy(s["path"], YOLO_ROOT / split / "images" / s["path"].name)
            rows = [" ".join(["0"] + [f"{v:.6f}" for v in to_yolo_label(b, s["width"], s["height"])]) for b in s["boxes"]]
            (YOLO_ROOT / split / "labels" / f"{s['path'].stem}.txt").write_text("\n".join(rows) + "\n")
    config = {"path": str(YOLO_ROOT), "train": "train/images", "val": "valid/images", "nc": 1, "names": ["person"]}
    config_path = YOLO_ROOT / "data.yaml"
    config_path.write_text(yaml.safe_dump(config))
    return config_path


def print_progress(trainer: BaseTrainer) -> None:
    """정해진 주기마다 검증 성능을 한 줄로 출력합니다."""
    epoch = trainer.epoch + 1
    if epoch % PRINT_EVERY == 0 or epoch == 1:
        print(f"epoch {epoch:3d} | mAP50 {trainer.metrics['metrics/mAP50(B)']:.3f} | mAP50-95 {trainer.metrics['metrics/mAP50-95(B)']:.3f}", flush=True)


def main() -> None:
    device = 0 if torch.cuda.is_available() else "mps" if torch.backends.mps.is_available() else "cpu"
    train, valid = load_split()
    print("train:", len(train), "/ valid:", len(valid), "/ device:", device)

    # 1) 라벨 한 줄 확인과 되돌리기 검사
    config_path = write_dataset(train, valid)
    first = train[0]
    lines = (YOLO_ROOT / "train" / "labels" / f"{first['path'].stem}.txt").read_text().strip().splitlines()
    print("라벨 파일", first["path"].stem + ".txt:", *lines, sep="\n  ")
    for line, box in zip(lines, first["boxes"]):
        restored = yolo_to_xyxy([float(v) for v in line.split()[1:]], first["width"], first["height"])
        assert max(abs(a - b) for a, b in zip(restored, box)) < 1.0, (restored, box)
    print("되돌린 박스가 원래 박스와 1픽셀 이내: 통과")

    # 2) 사전학습 모델(COCO 80클래스)로 검증 이미지 한 장
    pretrained = YOLO(WEIGHTS)
    print(f"사전학습 {WEIGHTS}: 클래스 {len(pretrained.names)}개, 파라미터 {sum(p.numel() for p in pretrained.model.parameters()) / 1e6:.1f}M")
    sample_image = str(YOLO_ROOT / "valid" / "images" / valid[0]["path"].name)
    result = pretrained(sample_image, verbose=False)[0]
    names = [result.names[int(c)] for c in result.boxes.cls]
    print(f"사전학습으로 {valid[0]['path'].name}: {dict((n, names.count(n)) for n in sorted(set(names)))} / 정답 사람 {len(valid[0]['boxes'])}명")

    # 3) 전이학습
    start = time.time()
    model = YOLO(WEIGHTS)
    model.add_callback("on_fit_epoch_end", print_progress)
    model.train(data=str(config_path), imgsz=IMAGE_SIZE, batch=BATCH, epochs=EPOCHS, device=device,
                project=str(RUN_DIR), name="person", exist_ok=True, seed=SEED, plots=False)
    print(f"학습 시간: {time.time() - start:.0f}초 ({EPOCHS} epoch)")

    # 4) best.pt를 명시적으로 불러 평가
    best = YOLO(str(RUN_DIR / "person" / "weights" / "best.pt"))
    metrics = best.val(data=str(config_path), imgsz=IMAGE_SIZE, plots=False, device=device, verbose=False)
    print(f"best.pt  mAP50 = {metrics.box.map50:.3f} / mAP50-95 = {metrics.box.map:.3f} / 클래스 {best.names}")
    with open(RUN_DIR / "person" / "results.csv") as f:
        rows = list(csv.DictReader(f))
    best_row = max(rows, key=lambda r: float(r["metrics/mAP50-95(B)"].strip()))
    print("가장 좋은 epoch:", int(float(best_row["epoch"])))

    # 5) 기준 점수와 탐지 수
    counts = {conf: len(best.predict(sample_image, conf=conf, verbose=False)[0].boxes) for conf in (0.25, 0.5, 0.9)}
    print("conf별 탐지 수:", counts, "/ 정답", len(valid[0]["boxes"]))
    assert counts[0.25] >= counts[0.5] >= counts[0.9]   # 기준을 높이면 줄어들기만 한다
    total = sum(len(r.boxes) for r in best.predict([str(YOLO_ROOT / "valid" / "images" / s["path"].name) for s in valid], conf=0.5, verbose=False, stream=True))
    print("검증 34장 conf 0.5 탐지 합계:", total, "/ 정답", sum(len(s["boxes"]) for s in valid))


if __name__ == "__main__":
    sys.exit(main())

"""8차시 실습: 고르는 데 쓴 데이터와 성적을 매기는 데이터를 나눈다(학습 / 검증 / 시험).

lab5의 학습 136장을 다시 학습 102장, 검증 34장으로 나누고, lab5의 검증 34장은 '시험'으로만 쓴다.
best.pt는 검증으로 고르므로 검증 점수는 낙관적이다. 시험 점수와 얼마나 다른지 잰다.
"""
import random
import shutil
import sys
import time

import yaml
from ultralytics import YOLO

from common import load_split
from common_yolo import HERE, IMAGE_SIZE, pick_device
from lab5_yolo11 import BATCH, SEED, WEIGHTS, to_yolo_label

SPLIT_ROOT = HERE / "data" / "PennFudan_3way"
RUN = HERE / "runs" / "person_3way"
EPOCHS = 50
VALID_SHARE = 0.25   # 학습 136장 가운데 검증으로 뗄 몫


def write_split(name: str, samples: list[dict]) -> None:
    for sub in ("images", "labels"):
        (SPLIT_ROOT / name / sub).mkdir(parents=True)
    for s in samples:
        shutil.copy(s["path"], SPLIT_ROOT / name / "images" / s["path"].name)
        rows = [" ".join(["0"] + [f"{v:.6f}" for v in to_yolo_label(b, s["width"], s["height"])]) for b in s["boxes"]]
        (SPLIT_ROOT / name / "labels" / f"{s['path'].stem}.txt").write_text("\n".join(rows) + "\n")


def main() -> int:
    device = pick_device()
    train_all, test = load_split()
    shuffled = train_all.copy()
    random.Random(SEED).shuffle(shuffled)
    n_valid = int(len(shuffled) * VALID_SHARE)
    valid, train = shuffled[:n_valid], shuffled[n_valid:]
    shutil.rmtree(SPLIT_ROOT, ignore_errors=True)
    for name, part in (("train", train), ("valid", valid), ("test", test)):
        write_split(name, part)
    names = {n: {s["path"].name for s in p} for n, p in (("train", train), ("valid", valid), ("test", test))}
    assert not (names["train"] & names["valid"]) and not (names["train"] & names["test"]) and not (names["valid"] & names["test"])
    print(f"학습 {len(train)} / 검증 {len(valid)} / 시험 {len(test)}  (겹치는 사진 없음)")
    config = {"path": str(SPLIT_ROOT), "train": "train/images", "val": "valid/images", "test": "test/images", "nc": 1, "names": ["person"]}
    (SPLIT_ROOT / "data.yaml").write_text(yaml.safe_dump(config))

    start = time.time()
    YOLO(WEIGHTS).train(data=str(SPLIT_ROOT / "data.yaml"), imgsz=IMAGE_SIZE, batch=BATCH, epochs=EPOCHS, device=device,
                        project=str(RUN.parent), name=RUN.name, exist_ok=True, seed=SEED, plots=False, verbose=False)
    print(f"학습 {time.time() - start:.0f}초")
    for weights in ("best.pt", "last.pt"):
        model = YOLO(str(RUN / "weights" / weights))
        row = []
        for split in ("val", "test"):
            box = model.val(data=str(SPLIT_ROOT / "data.yaml"), split=split, imgsz=IMAGE_SIZE, plots=False, device=device, verbose=False).box
            row.append(f"{'검증' if split == 'val' else '시험'} mAP50 {box.map50:.3f} / mAP50-95 {box.map:.3f}")
        print(f"{weights:8s}: " + " | ".join(row))
    return 0


if __name__ == "__main__":
    sys.exit(main())

11 · 용어 사전

        
막히면 여기로

      

      
Penn-Fudan Pedestrian
보행자 탐지 데이터셋. 170장의 사진과 사람별 인스턴스 마스크(PedMasks)가 있습니다. 원 배포처 조건을 따릅니다.

      
인스턴스 마스크
사진의 픽셀마다 “사람 1, 사람 2, 배경 0”을 적어 둔 이미지. 같은 클래스라도 개체를 구분합니다.

      
xyxy
박스를 (왼쪽 위 x, 왼쪽 위 y, 오른쪽 아래 x, 오른쪽 아래 y)로 표현. 여기서 x2·y2는 exclusive(그 좌표는 포함하지 않음)라서 max+1을 씁니다.

      
YOLO 라벨 형식
class cx cy w h. cx·cy·w·h는 이미지 크기로 나눈 0~1 값입니다. 클래스 번호가 맨 앞에 옵니다.

      
split / train / valid / test
데이터를 학습용·검증용·시험용으로 나눈 것. 검증은 모델 선택에, 시험은 마지막 성적에 씁니다. 서로 겹치면 안 됩니다.

      
seed
난수 시작 번호. 같은 seed면 같은 섞기/초기화가 재현됩니다. 여기서는 1729.

      
전이학습 (transfer learning)
큰 데이터로 미리 학습된 모델에서 시작해 새 데이터에 맞게 다시 학습하는 것. lab5가 COCO 학습 YOLO11s에서 시작합니다.

      
mAP50 / mAP50-95
평균 정밀도(AP)를 클래스 평균한 지표. mAP50은 IoU 0.5 기준, mAP50-95는 IoU 0.5~0.95를 10단계로 평균해 더 엄격합니다.

      
conf (confidence threshold)
예측 점수가 이 값 이상인 것만 남기는 기준. 높이면 탐지 수가 줄고 정밀도가 오르는 경향이 있습니다. lab5는 0.25/0.5/0.9로 단조 감소를 확인합니다.

      
best.pt / last.pt
ultralytics가 남기는 체크포인트. best.pt는 검증 지표가 가장 좋았던 epoch, last.pt는 마지막 epoch의 가중치입니다.

      
data.yaml
YOLO 데이터셋 설정 파일. path, train, val, (선택) test, nc, names를 담습니다.

      
SSL 인증서 검증
HTTPS 서버가 제시한 인증서가 믿을 만한 CA 목록에 의해 서명됐는지 확인하는 절차. 회사·학원 프록시가 인증서를 바꿔 끼우면 실패할 수 있습니다.

      
PENN_DATA_ROOT
데이터 위치를 바꾸는 환경변수. 이 폴더 아래에 PennFudanPed가 있어야 합니다.
