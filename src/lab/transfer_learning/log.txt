## 변경 전 (원본 baseline) → 변경 후

### [바꿀 곳 1] 변환 (증강)
- IMAGE_SIZE: 220 → 224 (룰 상한까지 활용)
- train_transform: Resize(220)+CenterCrop (증강 전무)
  → RandomResizedCrop(224, scale=(0.65,1.0), ratio=(0.75,4/3), BICUBIC)
     + RandomHorizontalFlip(0.5)
     + ColorJitter(0.2, 0.2, 0.2, 0.05)   # hue는 0.05로 제한 — 꽃은 색이 라벨 신호라 강한 hue 금지
- eval_transform: Resize(220)+CenterCrop(220) → Resize(224)+CenterCrop(224)
  # Resize(256)+CC(224)는 "입력 224px 초과" 그레이존 → 안전하게 미채택
- 신규: squish_transform() — TTA 다양성용 224×224 스퀴시 뷰 (입력 224px, 룰 준수)
- 금지 유지: vflip 불사용, 강한 RandAugment/mixup 미채택(1,020장에서 수렴 안정성)

### [바꿀 곳 2] 모델
- 모델 그대로: resnet18(weights=ResNet18_Weights.IMAGENET1K_V1), fc → nn.Linear(512, 102)
- requires_grad: 전부 True (전체 미세조정) — "2단계 vs 풀학습" 논쟁은 [4] 판별 LR로 절충

### [바꿀 곳 3] 손실
- CE → CE + label_smoothing=0.1 (실험 축 단일 유지; focal loss는 패널 5/5 스킵 합의)

### [바꿀 곳 4] 옵티마이저 · 스케줄
- Adam(lr 1e-3 균일, 스케줄 없음) →
  AdamW 판별 LR:
    - 몸통(conv/layer 파라미터 weight): lr=1e-4, weight_decay=0.05
    - 머리(fc) + BN affine + 모든 bias: lr=1e-3, weight_decay=0
    # 근거: 새 fc의 초기 큰 gradient가 1e-3 균일 LR에서 몸통 역류 → LR 분리로 해결
    #       wd는 bias/BN에 걸지 않는 표준 관행
- 스케줄: cosine annealing(0-based epoch, eta_mul→0) + 2 epoch linear warmup
  (LambdaLR: warmup 동안 (e+1)/2, 이후 0.5*(1+cos(pi*t)))

### [바꿀 곳 5] 학습 루프
- EPOCHS: 10 → 40 (총 step 320 → 1,280)
- 평균화: EMA(폐기) → **SWA**: 마지막 10 에폭 체크포인트 동일 가중 평균 + BN 재추정
  (학습 데이터, 증강 없음, forward only — no_grad, 라벨 미사용 → 룰 준수, 모델 1개)
  # v1 EMA: 랜덤초기화 오염 (검증 0.008~0.14) → 지연 시작해도 에폭당 갱신으로 버그(0.04 고정)
  # v2: 지연 시작했으나 ema_update가 에폭당 1회 → decay 0.999×39회 = 사실상 얼어버림
  # v3: 지수 평균 수학 자체를 제거 (동일 가중 평균 SWA로 교체)
- best-val 체크포인트 롤백: raw/SWA 후보 중 좋은 쪽 최종 채택
- 신규 BN running-stat 보호: 매 epoch model.train() 직후 모든 BatchNorm2d.eval() 처리
  # 근거: 1,020장/배치32 소배치 노이즈로 running stats 오염 방지 (Beam·Big Pickle 공동 지적)
  # 가중치(γ,β)는 학습 지속 — 통계만 고정

### predict() — TTA
- 단일 뷰 argmax → 4뷰 softmax 확률 평균:
    1) Resize(224)+CC(224) 원본
    2) 원본 + hflip
    3) Resize((224,224)) 스퀴시
    4) 스퀴시 + hflip
  # 확률(softmax) 평균 채택, logit 평균은 과신뢰 view에 끌리므로 제외
  # val에도 동일 TTA를 적용하는 것은 아님(선택 기준 = plain eval acc, 보수적)

### main()
- 기존 구조 유지(학습 → 검증 정확도 출력 → submission.csv 저장)

## 미채택 사항 (룰/안정성 근거)
- val 합치기: README 원문은 허용하지만 표 슬라이드 "하면 안 된다"에 명시 안 됨 + 검증
  정확도 목표(92% 측정)를 무의미화 → 이번 런처에서 미채택
- Resize(256)+CC(224) eval: "입력 ≤224px" 엄격 해석 리스크 → 미채택
- mixup/cutmix, TrivialAugment, ArcFace, focal: 2모델 앙상블용 모델 B(seed 1 + scale 0.5
  + 약증강) 후보로 예약 — 현재는 단일 모델 실행
- EMA IllegalStateException 등 트릭(emotion/dropoff) 없음 — 지적사항 반영 완료
